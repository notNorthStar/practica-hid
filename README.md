# Práctica HID — Archivo de ejemplo

Repositorio de apoyo para una **práctica educativa de ciberseguridad** sobre
inyección HID (BadUSB) con un dispositivo Digispark rev3.

El único propósito de este repo es alojar un archivo de texto de ejemplo
(`ejemplo.txt`) que el dispositivo descarga y abre para demostrar el flujo
completo de un payload **inofensivo**.

## Contenido

- `ejemplo.txt` — archivo de texto que se descarga y se abre en el Bloc de notas.

## URL raw

El sketch descarga el archivo desde:

```
https://raw.githubusercontent.com/USUARIO/REPO/main/ejemplo.txt
```

Sustituye `USUARIO` y `REPO` por los tuyos.

## Aviso

Material estrictamente educativo, para ejecutarse en tu propia máquina.
El payload no contiene código malicioso: solo descarga y muestra un `.txt`.
